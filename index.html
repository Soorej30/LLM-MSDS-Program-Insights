GitHub Sync Setup
Connect this tool to a GitHub repository. All team members who open the shared link will read from and write to the same data/entries.json file automatically.
Create a token at GitHub → Settings → Developer settings → Personal access tokens.
For a public repo, enable public_repo scope. For a private repo, enable repo scope.
Each team member should use their own token — it's stored only in their browser.
